## Architectural Philosophy and Experimentation Routes

My work focuses on several foundational engineering principles:

1. Local-First & Client-Side Edge Computing:
   Modern web browsers and desktop runtimes possess immense untapped processing power. Rather than relying on fragile cloud APIs or server-side rendering for real-time tasks, my audio applications and analysis tools run 100% client-side using WebAudio API, WebAssembly (WASM), and Electron. Audio processing, FFT analysis, and speech phonetics execute entirely in local memory with zero latency and zero data leakage.

2. Algorithmic Determinism Over Black Boxes:
   While machine learning provides exceptional generative capabilities, creative tools require predictability, repeatability, and precision. Across music theory engines, vector geometry generators, and harmonic analyzers, I build deterministic algorithmic pipelines based on formal mathematical models (such as Krumhansl-Schmuckler tonal profiles, jazz voice-leading rules, and SVG vector coordinate transforms).

3. Autonomous Agent Economics & Context Preservation:
   Large Language Model (LLM) agents struggle with context degradation, hallucinations, and state drift during multi-turn pair programming sessions. My research in AI tooling focuses on state preservation protocols, strict token budgeting, and deterministic handoff schemas that maintain lossless technical context across session boundaries.

4. Reciprocal Copyleft & Independent Software Protection:
   All original software under this portfolio is licensed under the GNU General Public License v3.0 (GPL-3.0). This ensures that independent open-source creative technology cannot be co-opted into proprietary closed-source commercial platforms without sharing source code back to the community.

### 1. Audio DSP, WebAudio, and Music Technology

Developing professional audio production tools that bring studio-grade digital signal processing directly into browsers and Digital Audio Workstations:

- Algorithmic DSP Transformations: Implemented over 60 hand-crafted audio processing modules in pure TypeScript using the WebAudio API, including Multi-Band Dynamic Range Compressors, Broadcast DRC, Sinc Resamplers, Algorithmic Reverbs (Plate, Spring, Room, Gated), Mid-Side Stereo Matrices, and Spectral Brickwall Filters.
- Client-Side WASM Acoustic Phonetics: Integrated compiled Praat C/C++ runtimes via WebAssembly (praat-wasm) to perform real-time vocal analysis in browser threads: Fundamental Frequency ($F_0$), formant dispersion ($F_1$–$F_4$), cycle-to-cycle jitter/shimmer perturbation, and Harmonics-to-Noise Ratio (HNR).
- Embedded Neural Performance Systems: Built a real-time neural network mixer for live dub music performance (dub-assistant-neural-mixer) featuring a lightweight Multilayer Perceptron (MLP) written in pure JavaScript, running online backpropagation across 24 concurrent send parameters inside Max for Live without blocking Ableton's audio thread.
- Algorithmic Music Theory & Harmony: Designed Python music theory engines that parse and reharmonize progressions into Neo-Soul/Gospel extensions, Modern Jazz Tritone Substitutions ($subV_7$), and Cinematic Modal Interchange, exporting humanized Standard MIDI Files (.mid) with custom Drop-2 and Ambient Pad voicings.
- Binary Audio Preset Forensics: Engineered zero-dependency systems tools (ableton-preset-sample-relinker) that decompress and reconstruct gzipped XML preset streams (.adg/.adv), relinking missing sample dependencies directly without creating duplicate audio bloat.

### 2. Autonomous AI and Agent Reasoning Architectures

Designing context-aware autonomous agent workflows, pair-programming handoff frameworks, and cognitive assistance systems:

- Autonomous Deep Research Pipelines: Architected multi-stage analyst agents (gemini-deep-research-agent) in React 19 and TypeScript that dynamically break ambiguous queries into targeted sub-searches, execute iterative web exploration, evaluate source authority, and compile structured, cited markdown reports.
- AI Session Handoff & Context Preservation: Formulated the AI Session Handoff Protocol, an industry-first dual-profile prompt architecture (-short ~250–500 tokens vs -long lossless) designed for Claude Code, Grok CLI, Antigravity, and Cursor. Eliminates context degradation and hallucinated diffs across long multi-turn programming sessions.
- Cognitive Mental Models & Reasoning Workbench: Developed mindtools-suite, a full-stack cognitive assistance studio featuring 15+ specialized reasoning engines: first-principles decomposition, cognitive bias auditing, trade-off matrix evaluation, and prompt optimization.
- Local-First AI Archive Systems: Engineered grok-archive-viewer, a private offline Electron/TypeScript desktop workbench that parses massive JSON conversation exports into searchable, categorized interfaces with zero cloud transmission.

Pioneering forensic speech profiling, broad phonemic phonetic translation, and synchronized multi-speaker media generation:

- Computational Idiolect & Phonetic Translation: Developed pronunciation dictionary compiler engines that capture how speakers actually talk in acoustic reality (vowel shifts, cadence elongations, dropped consonants, and regional vernacular) mapped strictly into broad phonemic IPA syntax (<<ˈ|...>>) based on the Wells 24 Lexical Sets.
- End-to-End Voice AI Media Pipelines: Engineered cartesia-voice-toolkit, an automated pipeline that searches the web for speech samples, isolates clean vocals via neural source separation (RoFormer / Demucs), clips articulate reference segments under strict size ceilings, generates multi-voice dialogue scripts, and renders synchronised 1080p split-screen animated video with active speaker highlights.
- Forensic Voice Biometrics: Formulated standardized 10-dimension acoustic specification schemas (voice-biometric-profiling-engine) analyzing time-domain waveforms, spectral tilt, formant bandwidths ($B_1$–$B_4$), and vocal tract biomechanics for zero-shot neural TTS calibration.

### 4. Procedural Vector Mathematics and Generative UI

Building mathematical vector graphics engines, avionics telemetry interfaces, and design token architectures:

- Universal Design Token Engine: Created design-templates-engine, a master design specification comprising 179 production-grade aesthetic design systems (Nordic Monolith, OLED Cyberdeck, Swiss Bauhaus, Braun Functionalist, Avionics HUD, 808 Programmer, Solarpunk, etc.).
- Procedural Tactical HUD & Hardware Reticles: Built procedural-hud-designer, a pure Python procedural vector generation engine that calculates and draws mathematical aerospace HUDs, radar reticles, and 19-inch audio rack hardware faceplates with millimeter-accurate SVG geometries.
- Hardware-Accelerated Vector Animation: Developed canvas-svg-animator-engine, converting static SVG vector paths into glowing laser-trace drawing animations, neon breathing pulses, and oscilloscope waveforms rendered via HTML5 Canvas and CSS filters.
- Algorithmic SVG Vector Normalization: Engineered vector-icon-pack-builder, an algorithmic compiler that parses arbitrary SVG geometries and normalizes stroke weight, corner radii, and line caps to match exact design token constraints.

### 5. Systems Diagnostics and Data Pipelines

Creating high-throughput data extraction engines and native diagnostic utilities:

- System Log & BSOD Crash Translator: Created windows-system-log-translator, a native desktop application (Python + pywebview + WMI) that monitors Windows Event Viewer logs, decodes hexadecimal BugCheck BSOD codes, and translates complex driver errors into actionable, plain-English solutions.
- Documentation-to-Database Pipelines: Built docs-database-parser, an automated ingestion pipeline that compiles technical manuals, web guides, and YouTube transcripts into dual-access knowledge bases (SQLite FTS5 full-text search, Apache Parquet columnar storage, and modular Markdown).
- Automated Video-to-Guide Pipelines: Created youtube-tutorial-capture-engine, extracting video transcripts with millisecond timestamps, isolating keyframe screenshots at procedural steps using ffmpeg, and compiling publication-grade PDF and Markdown manuals.
- Polite Technical Documentation Crawlers: Built web-documentation-crawler, an automated crawler respecting robots.txt that recursively traverses multi-page technical documentation trees, strips navigation chrome, and compiles offline single-file PDF reference manuals.
