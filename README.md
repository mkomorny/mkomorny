### 🎨 Featured Creative & Technical Domains

#### 🎧 Audio DSP, WebAudio & Music Technology
- [**`producer-tools-dsp-suite`**](https://github.com/mkomorny/producer-tools-dsp-suite) — Full-stack WebAudio DSP suite featuring 60+ algorithmic audio transformations, interactive Tone.js Piano Roll, and client-side Praat-WASM vocal phonetics.
- [**`live-skin-builder`**](https://github.com/mkomorny/live-skin-builder) — Zero-dependency browser workbench that maps color palettes onto Ableton Live 12 themes with real-time 1280x800 vector UI preview and `.ask` compiler.
- [**`dub-assistant-neural-mixer`**](https://github.com/mkomorny/dub-assistant-neural-mixer) — Max for Live real-time neural performance mixer with an embedded JavaScript Multilayer Perceptron (MLP) mapping 3 macro knobs across 24 concurrent delay/reverb sends.
- [**`algorithmic-reharmonizer`**](https://github.com/mkomorny/algorithmic-reharmonizer) — Algorithmic music theory engine transforming chord progressions into Neo-Soul/Gospel extensions, Jazz Tritone Substitutions, and Cinematic Modal Interchange.
- [**`midi-chord-progression-builder`**](https://github.com/mkomorny/midi-chord-progression-builder) — Programmatic MIDI generation engine creating humanized `.mid` files with custom voicings (Drop-2, Open, Ambient Pad) and pianistic velocity dynamics.
- [**`ableton-preset-sample-relinker`**](https://github.com/mkomorny/ableton-preset-sample-relinker) — Zero-dependency utility parsing gzipped XML presets (`.adg`/`.adv`) and dynamically relinking missing audio sample paths without duplicating files.

- [**`ai-session-handoff-protocol`**](https://github.com/mkomorny/ai-session-handoff-protocol) — Precision context-preservation framework and dual-profile prompt architecture for autonomous AI agents and coding assistants.
- [**`mindtools-suite`**](https://github.com/mkomorny/mindtools-suite) — AI-powered cognitive assistance and mental model studio featuring 15+ specialized reasoning, bias auditing, and communication tools.
- [**`grok-archive-viewer`**](https://github.com/mkomorny/grok-archive-viewer) — Privacy-first, offline desktop viewer for local Grok conversation export archives (Electron + Vite + TypeScript).
- [**`ai-chat-session-exporter`**](https://github.com/mkomorny/ai-chat-session-exporter) — Universal cross-platform transcript exporter parsing AI sessions into clean Markdown, HTML, JSON, and CSV.

#### 🎙️ Voice AI & Speech Science
- [**`cartesia-voice-toolkit`**](https://github.com/mkomorny/cartesia-voice-toolkit) — End-to-end voice AI pipeline: audio harvester, broad IPA pronunciation dictionary compiler, multi-voice dialogue synthesis, and 1080p video rendering.
